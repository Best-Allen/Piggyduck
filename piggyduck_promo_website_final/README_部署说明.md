# 一只居和鸭 PiggyDuck 宣传网站

这是一个可直接部署的静态网站，用于宣传一只居和鸭美股研究与会员直播社群。

## 文件结构

- `index.html`：网站主页面
- `assets/css/styles.css`：网站样式
- `assets/js/main.js`：复制联系方式、移动端菜单等交互
- `assets/img/avatar.png`：头像素材
- `assets/img/payment-methods.png`：会员付款方式图，二维码使用原图裁切，未重绘
- `assets/files/member-rules-2025-v4.pdf`：完整会员说明与群规

## 本地预览

解压后双击 `index.html` 即可打开。

## 部署到 GitHub Pages

1. 解压 `piggyduck_promo_website.zip`。
2. 把 `piggyduck_promo_website_final` 文件夹内的所有文件上传到 GitHub Pages 仓库根目录。
3. 确保 `index.html` 位于仓库根目录。
4. 在 GitHub Pages 设置里选择部署分支。
