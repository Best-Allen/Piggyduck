# 一只居和鸭 PigDucker 主页

这是一个可直接部署到 GitHub Pages 的静态网站版本。

## 这版做了什么

- `index.html` 放在仓库根目录，上线后可访问 `https://best-allen.github.io/Piggyduck/`
- `profile/index.html` 改成自动跳转，旧地址 `https://best-allen.github.io/Piggyduck/profile/` 不会失效
- `assets/css/styles.css` 负责页面视觉风格
- `assets/js/main.js` 负责移动端菜单和复制微信号
- `assets/img/` 保留头像和付款二维码素材
- `assets/files/member-rules-2025-v4.pdf` 保留会员说明 PDF

## 部署方式

1. 把本文件所在文件夹里的内容上传到 `Best-Allen/Piggyduck` 仓库根目录。
2. 确认仓库根目录有 `index.html`、`assets/`、`profile/`。
3. GitHub Pages 继续使用 `main` 分支根目录部署。
4. 等 GitHub Pages 刷新后，新的短地址是 `https://best-allen.github.io/Piggyduck/`。

## 更短域名

如果想去掉 `best-allen.github.io` 和 `/Piggyduck/`，需要绑定自定义域名。具体步骤见 `SHORT_URL_GUIDE.md`。
